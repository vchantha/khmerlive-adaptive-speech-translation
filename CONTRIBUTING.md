# Contributing

Thank you for supporting KhmerLive AI research.

## Workflow
1. Open an issue explaining the research or engineering change and version scope (V1, V2 or shared).
2. Include acceptance criteria, data/privacy implications, test strategy and dependencies.
3. Make focused changes on a feature branch and request review before merging.
4. Include reproducible commands and clear evidence; do not describe untested code as working.
5. Run formatting, tests and model-evaluation gates applicable to the change.

## Research integrity
Never commit personal recordings, secrets, unlicensed datasets, or model weights without distribution rights. Keep source transcript corrections separate from translation corrections. All model promotions require reproducible held-out evaluation and explicit approval.

## Code and documentation quality
Use type hints and unit tests for Python, TypeScript checks for UI, Django/Alembic-style migration discipline as chosen by the team, and versioned API contracts. Document assumptions and implementation status.

## Licensing
The repository's code license has not yet been selected; confirm reuse rights before contributing code or external assets.
